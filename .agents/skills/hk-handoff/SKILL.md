# 세션 넘기기

맥락이 길어지면 응답이 느려지고 앞의 결정을 잊는다. 압축에 맡기지 말고 직접 넘긴다.
**넘길 시점**: 첫 완주 직후, 큰 방향 전환 직후, 대화가 매우 길어졌을 때.

## 1. HANDOFF.md 작성

템플릿 `.hk/templates/HANDOFF.md`를 과제 루트로 복사해 채운다. 각 항목은 3줄 이내. 추측을 쓰지 않는다.

- 목표 한 문장과 성공 기준 (TASK.md 링크)
- 지금 단계와 남은 시간
- 완료 조건별 상태 (PASS / FAIL / NOT_RUN)
- 사용자가 내린 결정 중 다음 세션이 반드시 지켜야 할 것
- 진행 중이던 작업과 다음 한 걸음 (실행할 명령까지)
- 알려진 위험과 하지 말아야 할 것

## 2. 커밋

`git add -A && git commit -m "docs: handoff"`

## 3. 새 세션 첫 메시지 (사용자에게 그대로 알려준다)

```
AGENTS.md를 작업 규칙으로 따라줘. HANDOFF.md, TASK.md, DECISIONS.md를 읽고
지금 단계, 남은 일, 지켜야 할 결정을 3줄로 요약한 뒤 HANDOFF.md의 다음 한 걸음부터 진행해.
```

새 세션은 요약이 HANDOFF.md와 다르면 진행하지 말고 차이를 보고한다.
