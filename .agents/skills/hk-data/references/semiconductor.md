# 반도체 제조 데이터 참고 (과제 정의가 항상 우선)

과제 README나 데이터 사전의 정의가 있으면 그것을 따른다. 아래는 용어를 해석할 때의 출발점이다.

## 단위와 키

| 용어 | 의미 | 데이터에서 주의 |
|---|---|---|
| Lot | 함께 공정을 진행하는 웨이퍼 묶음(보통 25장) | 같은 lot은 공정 조건을 공유한다. 학습과 평가에 나눠 넣으면 누수 |
| Wafer | 칩을 만드는 원판 | wafer_id가 lot마다 1~25로 재사용되면 키는 `(lot_id, wafer_id)` |
| Die / Chip | 웨이퍼 위 개별 칩 | 웨이퍼 맵 데이터는 die 좌표(x, y) 단위 |
| Step / Operation | 공정 단계 | 같은 웨이퍼가 단계마다 여러 행을 가진다 |
| Equipment / Chamber | 설비와 그 안의 처리 공간 | 특정 챔버 집중은 원인 후보. 새 챔버가 들어오면 챔버 ID 피처는 일반화되지 않는다 |
| Recipe | 공정 조건 묶음 | 레시피가 다르면 센서 분포가 다르다. 레시피별 정규화를 검토 |

## 데이터 종류

| 종류 | 내용 | 흔한 과제 |
|---|---|---|
| FDC (설비 센서) | 공정 중 압력, 온도, RF 파워, 가스 유량 등의 시계열 또는 요약 통계 | 설비 이상 탐지, 불량 사전 예측 |
| Metrology (계측) | 공정 후 두께, CD(선폭), 오버레이 측정 | 계측값은 공정 **후** 값이다. 그 공정의 불량 예측 피처로 쓰면 누수 |
| Inspection (검사) | 결함 위치, 크기, 분류 | 결함 건수 ≠ 불량 칩 수 |
| EDS / Test (전기 검사) | 칩별 전기 특성 판정, 빈(bin) 코드 | 최종 양불 라벨의 출처인 경우가 많다 |
| Wafer map | die 좌표별 양불 | 패턴 분류(center, edge-ring, scratch, local 등). 공개 데이터 WM-811K |

## 지표

| 지표 | 정의 | 주의 |
|---|---|---|
| 수율 | `sum(양품) / sum(투입)` | 행별 수율의 평균과 다르다. 분모 0은 산출 불가 |
| 미탐 (Miss, FN) | 불량을 정상으로 판정 | 다음 공정으로 불량이 넘어가 비용이 크다. 보통 재현율을 우선 |
| 오탐 (False alarm, FP) | 정상을 불량으로 판정 | 재검사, 설비 정지 비용. 처리 용량 제약과 함께 본다 |
| 재현율 | TP / (TP + FN) | 불량 중 잡아낸 비율 |
| 정밀도 | TP / (TP + FP) | 불량이라고 한 것 중 진짜 비율 |
| 상위 k% 재현율 | 점수 상위 k%를 걸렀을 때 잡힌 불량 비율 | 재검사 용량이 정해진 현장에 맞는 지표 |

## SPC

- 관리도(I-MR, X-bar R 등)는 공정이 평소 범위를 벗어났는지 보는 도구다.
- 관리한계(평균 ± 3σ)는 **과거 안정 구간**으로 계산한다. 평가 구간을 섞으면 미래 정보가 들어간다.
- 관리한계는 규격한계(spec)와 다르다. 이탈은 조사 신호이지 불량 판정이 아니다.
- Cpk 같은 공정능력 지수는 규격한계가 주어졌을 때만 계산한다.
