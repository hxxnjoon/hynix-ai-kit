# 데이터 과제: 계산 전에 기준부터

반도체 회사 과제라는 이유로 모델이나 대시보드가 필요하다고 짐작하지 않는다. README가 요구한 것만 만든다.
원본 데이터는 수정하지 않는다. 모든 점검은 다시 실행할 수 있는 스크립트로 남긴다.

## 1. 프로파일 (손으로 열지 않는다)

```bash
python3 .hk/tools/profile.py data/a.csv                       # 모양, 결측, 고유값, 중복, 의심 컬럼
python3 .hk/tools/profile.py data/a.csv --target label        # 타깃 분포, 단일 컬럼 누수 의심
python3 .hk/tools/profile.py data/a.csv --key lot_id,wafer_id # 키 중복 확인
python3 .hk/tools/profile.py join data/a.csv data/b.csv --on lot_id,wafer_id   # 조인 전후 행 수
```

## 2. 데이터 계약 (TASK.md에 문장으로)

- **한 행의 의미**: 웨이퍼 하나인지, 검사 시도 한 번인지, 결함 한 건인지, 센서 관측 한 번인지
- **식별 키**: 무엇이 대상 하나를 유일하게 정하는가. wafer_id가 lot마다 재사용되면 `(lot_id, wafer_id)`가 키다. 앞자리 0이 있는 ID는 문자열로 읽는다.
- **시간**: 시간대, 정렬 여부, 기간 경계(포함인지), 같은 대상의 반복 기록
- **지표의 분자와 분모**를 문장으로 먼저 쓴다
- **결측, 재검사, 제외 정책**: 근거가 없으면 담당자 질문으로 보낸다. 0이나 평균으로 임의로 채우지 않는다.

## 3. 반도체 집계 함정

용어와 데이터 종류(FDC, 계측, 검사, EDS, 웨이퍼 맵, SPC)가 낯설면 `references/semiconductor.md`를 읽는다.

| 함정 | 올바른 처리 |
|---|---|
| 수율을 행별 비율의 평균으로 계산 | `sum(양품) / sum(투입)`. 단순 평균이 필요하면 이름을 다르게 붙인다 |
| `1 - 결함수/검사수`를 수율로 사용 | 한 다이에 결함이 여러 개일 수 있다. 결함 건수와 불량 개체 수를 구분한다 |
| `lot_id`만으로 조인 | 1:N, N:M 조인으로 행이 불어난다. 조인 전후 행 수와 분모 합계를 대조한다. 필요하면 먼저 집계하고 조인한다 |
| 재검사 기록을 모두 더하거나 모두 삭제 | 최초 통과율, 최종 판정 통과율, 전체 시도 통과율을 구분하고 무엇을 쓸지 묻는다 |
| 관리한계 이탈을 불량으로 확정 | SPC 이탈은 조사할 신호다. 원인이나 불량 판정이 아니다. 규격 없이 임의 합격선이나 Cpk를 만들지 않는다 |
| 분모 0을 0%로 표시 | `산출 불가`로 표시한다 |
| 경계값 처리 미확정 | 기준과 같으면 통과인지(`>=` vs `>`) 근거와 함께 확정하고 테스트로 고정한다 |

## 4. 모델이나 예측이 있으면

- **기준선 먼저**: 다수 클래스, 단순 규칙, 무작위 선별의 수치를 먼저 구한다. 개선은 기준선 대비로 말한다.
- **누수 의심**: 판정 이후에만 알 수 있는 값(post, final, result, measure, judge, label, flag, defect_cnt 등), 타깃과 거의 1:1인 컬럼. 단일 컬럼 성능이 비정상적으로 높으면 누수 후보다.
- **분할은 실제 사용과 같게**: 시간이 있으면 과거로 학습, 미래로 평가. 같은 lot이나 설비가 학습과 평가에 걸치지 않게 한다(그룹 분할).
- **전처리, 인코딩, 오버샘플링, 임계값 결정은 학습 구간 안에서만** 한다. 오버샘플링은 분할 후 학습 세트에만.
- **지표는 현장 비용에 맞춘다**: 불균형이면 정확도를 주 지표로 쓰지 않는다. 미탐 비용이 크면 재현율, 처리 용량이 정해져 있으면 상위 k% 재현율(`python3 .hk/tools/metrics.py classify ... --k 0.1`).
- 모델 지표는 라이브러리 값과 `.hk/tools/metrics.py` 값으로 **두 번 계산해 맞춘다.**
- 결과에는 모집단, 기간, 제외한 행 수와 이유, 기준선 대비 차이, 남은 한계를 붙인다.

## 5. 기록

- 데이터 처리 결정(제외, 대체, 키, 분모, 분할)은 DECISIONS.md에 `결정 / 대안 / 이유 / 근거 수치`로 남긴다.
- 손으로 계산한 작은 사례(정상, 분모 0, 결측, 중복 키, 경계값)를 테스트로 만든다.
- 데이터와 과제 내용은 응시 환경 밖으로 보내지 않는다.
