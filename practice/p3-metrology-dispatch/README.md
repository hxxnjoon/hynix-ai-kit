# 과제: 계측 장비 작업 배정

계측팀에서 요청이 왔습니다.

> "계측 대기 중인 lot이 쌓여서 일부가 너무 오래 기다려요. 오늘 주간 근무 동안 어느 장비에서 어떤 순서로 측정할지 정해 주세요."

## 제공 파일

- `data/lots.csv`: 오늘 계측 대기 lot (도착 시각, 레시피, 우선순위)
- `data/tools.csv`: 계측 장비 (측정 가능한 레시피, lot당 소요 시간)

## 제출물

- `schedule.csv`: `lot_id, tool_id, start, end` 컬럼. 모든 lot 포함
- 배정 방법과 판단 근거를 담은 문서

근무 시간은 08:00부터 20:00까지입니다. 궁금한 점은 계측팀 담당자에게 문의하세요.
