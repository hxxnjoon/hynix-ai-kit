# 과제: 설비 알람 확인 도구

설비기술팀에서 요청이 왔습니다.

> "야간에 알람이 너무 많이 떠서 정말 중요한 걸 놓쳐요. 엔지니어가 아침에 볼 수 있게 정리해 주세요."

## 제공 파일

- `data/alarms.csv`: 지난 2주 설비 알람 기록
- `data/alarm_codes.csv`: 알람 코드 설명
- `data/equipment.csv`: 설비 목록

## 제출물

- 엔지니어가 브라우저에서 볼 수 있는 화면 (웹 서비스)
- `review_list.csv`: 정리 결과. `rank, equipment_id, alarm_code, first_time, last_time, count, reason` 컬럼
- 실행 방법과 판단 근거를 담은 문서

궁금한 점은 설비기술팀 담당자에게 문의하세요.
