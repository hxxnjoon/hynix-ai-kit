# 과제: 식각 공정 불량 웨이퍼 사전 선별

식각 수율팀에서 요청이 왔습니다.

> "계측 결과가 나오기 전에 불량 웨이퍼를 미리 걸러내고 싶어요. 한번 만들어 주세요."

## 제공 파일

- `data/etch_train.csv`: 과거 웨이퍼 기록 (라벨 `fail` 포함)
- `data/etch_new.csv`: 이번 주 웨이퍼 기록 (라벨 없음)

## 제출물

- `submission.csv`: `etch_new.csv`의 모든 웨이퍼에 대해 `lot_id, wafer_id, score, screen` 컬럼
  - `score`: 불량 가능성 점수 (높을수록 불량 의심)
  - `screen`: 재검사로 보낼 웨이퍼면 1, 아니면 0
- 실행 방법과 판단 근거를 담은 문서

궁금한 점은 수율팀 담당자에게 문의하세요.
